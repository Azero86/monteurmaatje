MonteurMaatje - VPS root build

Deze build is aangepast om vanaf de ROOT van een normale webserver te draaien:
  http(s)://jouwdomein.nl/

Er zijn geen /monteurmaatje/ base-paths meer nodig.

AANBEVOLEN NGINX WEBROOT
  /var/www/monteurmaatje

Kopieer de INHOUD van deze map naar:
  /var/www/monteurmaatje/

Voorbeeld Nginx server block:

server {
    listen 80;
    listen [::]:80;

    server_name _;

    root /var/www/monteurmaatje;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}

Daarna:
  nginx -t
  systemctl reload nginx

Let op:
- De website zelf werkt via HTTP.
- Voor PWA-installatie en serviceworker buiten localhost is HTTPS vereist.
- Voeg HTTPS toe zodra het domein naar de VPS wijst.
