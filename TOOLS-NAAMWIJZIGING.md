# Kennis → Tools

De zichtbare naam van de bestaande Kennis-sectie is gewijzigd naar **Tools**:
- ondermenu: Tools
- paginatitel: Tools

Interne IDs/routes (`knowledgeView`, enz.) zijn bewust niet hernoemd om onnodig regressierisico te vermijden.
De CV-vermogentool, temperatuurcorrectie, ketel-/parameterkoppelingen en technische toesteldata zijn inhoudelijk ongewijzigd.
