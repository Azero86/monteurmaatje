# GitHub Pages-aanpassing

Deze versie is gebaseerd op de aangeleverde site-ZIP.

Uitgangspunt:
- geen bestaande map verwijderd;
- geen bestaand bestand verwijderd;
- geen layout/data/functionele structuur gewijzigd.

Alleen aangepast:
- `.nojekyll` toegevoegd voor GitHub Pages;
- serviceworker verwijzingen naar bestaande versioned manifest/favicon-assets gecorrigeerd;
- serviceworker-cacheversie verhoogd;
- serviceworker-registratie geversioneerd zodat de update wordt opgepakt.

Alle bestaande mappen en bestanden uit de bron-ZIP zijn behouden.
