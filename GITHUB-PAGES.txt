MonteurMaatje - GitHub Pages build

Deze map is geschikt om als statische GitHub Pages-site te publiceren.
De app gebruikt relatieve paden, zodat hij zowel onder:
  https://<account>.github.io/<repository>/
als via een eventueel custom domain kan draaien.

Aanbevolen publicatie:
1. Zet de INHOUD van deze map in de gewenste GitHub repository.
2. GitHub -> Settings -> Pages.
3. Deploy from a branch -> kies de branch (bijv. main) en /(root).
4. Wacht tot Pages de deployment als succesvol toont en open de Pages-URL.

Belangrijk:
- .nojekyll staat bewust in deze map.
- VPS-INSTALL.txt is alleen documentatie voor de VPS; het beïnvloedt GitHub Pages niet.
- De technische toesteldata is niet inhoudelijk gewijzigd voor deze GitHub-versie.
